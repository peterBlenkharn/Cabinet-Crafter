# Support

Cabinet Crafter is maintained on a best-effort basis. The documentation and GitHub issue tracker are its public support channels.

## Start here

- [Windows Release Guide](docs/RELEASE_GUIDE.md) for downloading, verifying, starting and troubleshooting the application.
- [Documentation Index](docs/INDEX.md) for product, workflow and technical guidance.
- [Before You Cut](docs/BEFORE_YOU_CUT.md) before relying on fabrication output.

## Ask for help

Search the documentation and existing issues first. If you are still blocked, use the [help and usage form](https://github.com/peterBlenkharn/Cabinet-Crafter/issues/new?template=help.yml).

Include the Cabinet Crafter version, Windows version, workflow stage and what you have already tried. Remove personal or confidential project information before attaching files.

## Report a bug

Use the [bug report form](https://github.com/peterBlenkharn/Cabinet-Crafter/issues/new?template=bug.yml) for reproducible application faults or incorrect output.

## Suggest an improvement

Use the [feature request form](https://github.com/peterBlenkharn/Cabinet-Crafter/issues/new?template=feature.yml).

## Report a vulnerability

Do not open a public issue containing vulnerability or exploit details. Follow the [Security Policy](SECURITY.md).

## Fabrication responsibility

Support and generated files do not replace independent checks of dimensions, materials, tooling, CAM settings, machine behaviour or representative test cuts.
