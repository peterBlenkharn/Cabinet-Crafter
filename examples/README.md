# Example Projects

## Workshop Upright

[Workshop Upright](workshop-upright.cabinet.json) is a completed Standard upright project for exploring Cabinet Crafter without starting from a blank design.

It includes costed MDF stock and hardware, a validated three-sheet Area plan at 81.9% utilisation, and confirmed Design, Hardware, Review, Sheets and Export stages. Prices are illustrative and must be checked before purchasing.

To use it:

1. Open the project link above and choose **Download raw**.
2. Start Cabinet Crafter and choose **More > Open**.
3. Select `workshop-upright.cabinet.json`.
4. Use **More > Save as** before making changes.

Follow [Build Your First Cabinet](../docs/FIRST_PROJECT.md) for the illustrated walkthrough. Read [Before You Cut](../docs/BEFORE_YOU_CUT.md) before using any production geometry.
